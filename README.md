The Streamlit Banking Application is a simple web-based banking system developed using Python and Streamlit. This application allows users to perform basic banking operations such as creating an account, depositing money, withdrawing money, checking account balance, and updating mobile numbers through an interactive web interface.
The project demonstrates how Python Object-Oriented Programming (OOP) concepts can be integrated with Streamlit to build an interactive and user-friendly web application. The application is deployed using Streamlit Cloud, making it accessible online.
